# مداد — مكتبتك العربية

تطبيق ويب قابل للتثبيت (PWA) للبحث عن الكتب وقراءتها، والأولوية فيه للكتاب العربي.

- أقسام وتصنيفات، ومكتبة شخصية تحفظ أين وصلت بكل كتاب
- قارئ بخطوط ومظاهر متعددة، وتظليل، وعلامات، وفهرس، وقراءة صوتية
- نظام «المصادر» لربط مكتبات رقمية مرخّصة برابط
- يشتغل بدون إنترنت ويُضاف للشاشة الرئيسية

> نسخة أولى ببيانات تجريبية.
